Arduino & Nextion Setup Guide

  1. Download the zipped package file using the 'Download Package' button.
  2. Extract the contents to a folder on your computer (e.g., C:\EngineeringTools).
  3. Run the `arduino-1.8.18-windows.exe` installer and follow the standard instructions.
  4. Copy the included `Libraries` folder into your `Documents/Arduino/libraries` directory.
  5. Launch Nextion Editor setup if you intend to design HMI touchscreen interfaces.

MATLAB Simulation Models Setup

  1. Access the repository or download the `.zip` archive containing the `.m` files and Simulink `.slx` models.
  2. Open MATLAB and set the Current Folder path to the unzipped project directory.
  3. Run the startup script `init_params.m` to load system matrices and variables into the workspace.
  4. Launch Simulink and open the desired control system model (e.g., `digital_pid_sim.slx`).
